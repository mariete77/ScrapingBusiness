# 📱 Plantillas de Outreach para Bares y Restaurantes

Este documento contiene plantillas de mensajes para contactar a bares y restaurantes sin página web.

## 🎯 Servicios Ofrecidos

### 1. Página Web Profesional
- Mostrar el menú de forma visual y profesional
- Fotos de alta calidad de los platos
- Información clara: horarios, ubicación, contacto
- Reservas online
- Integración con redes sociales
- SEO local para aparecer en búsquedas

### 2. Aplicación Móvil de Pedidos
- Pedidos directos desde la mesa
- Menú digital interactivo
- Notificaciones cuando el pedido está listo
- Historial de pedidos y favoritos
- Promociones y descuentos push
- Integración con sistemas de pago

### 3. Dashboard de Análisis
- Control de ventas en tiempo real
- Análisis de platos más vendidos
- Detección de pérdidas y desperdicios
- Proyecciones de ingresos
- Reportes mensuales automáticos
- Alertas de stock bajo

### 🎯 Paquete Completo
Incluye los tres servicios anteriores con:
- ✅ Setup completo en 2 semanas
- ✅ Formación del personal
- ✅ Soporte técnico 1 año
- ✅ Actualizaciones gratuitas


## 🎯 Tips para Mejorar Tasa de Respuesta

1. **Personaliza siempre** - Usa el nombre del negocio y menciona el rating
2. **Envía en horas adecuadas** - No envíes en horarios punta (12:00-15:00, 20:00-23:00)
3. **Sigue** - Si no responden, envía 2-3 mensajes de seguimiento con intervalos de 3-5 días
4. **Usa emojis** - Hacen el mensaje más amigable y menos "spammy"
5. **Ofrece valor primero** - No vendas directamente, ofrece información útil
6. **Usa prueba social** - Menciona casos de éxito con números específicos
7. **Crea urgencia** - "Solo 3 plazas", "Oferta limitada", etc.
8. **Manténlo breve** - Mensajes largos no se leen

## 📊 Métricas a Medir

- Tasa de apertura de mensajes
- Tasa de respuesta
- Conversiones (demos agendadas, ventas cerradas)
- Tiempo de respuesta promedio
- Costo por adquisición
